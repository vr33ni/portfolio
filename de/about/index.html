Über Mich

Ich bin Full-Stack-Webentwicklerin mit über 5 Jahren Erfahrung im Aufbau skalierbarer und leistungsstarker Webanwendungen. Mein Schwerpunkt liegt auf modernen Frontend-Frameworks wie Vue.js und Stencil sowie auf der Backend-Entwicklung mit Node.js, Go und Java (Spring Boot).

Neben der App-Entwicklung bringe ich praktische Erfahrung in der Arbeit mit CI/CD-Pipelines, der Containerisierung mit Docker und der Bereitstellung von Anwendungen auf Plattformen wie OpenShift mit. Ich habe Unternehmen dabei unterstützt, produktionsreife Plattformen zu entwickeln, und konzentriere mich jetzt darauf, dieselbe Qualität für Startups, Agenturen und Unternehmen bereitzustellen, die sauberen und zuverlässigen Code benötigen.

Wobei ich helfen kann:

  • Erstellung schneller, responsiver SPAs mit Vue.js
  • Entwicklung wiederverwendbarer Webkomponenten mit Stencil
  • Entwicklung sicherer und skalierbarer REST-APIs (Node.js / Express / Java Spring Boot)
  • Integration von Drittanbieter-APIs, Datenbanken und Cloud-Plattformen
  • Behebung von Bugs, Leistungsoptimierung und Refactoring von Legacy-Code
  • Zusammenarbeit mit Designern oder Teams, um Spezifikationen in funktionierende Produkte umzusetzen
  • CI/CD-Pipelines, Docker und Deployment: Aufbau automatisierter Workflows mit GitHub Actions, Containerisierung von Anwendungen mit Docker und Deployment auf Plattformen wie OpenShift.

Ich lege großen Wert auf klare Kommunikation, saubere Architektur und schnelle Umsetzung. Wenn du eine zuverlässige Entwicklerin suchst, die Ergebnisse liefert — lass uns sprechen.
