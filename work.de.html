Morning Briefing Agent

Python · LangGraph · API Integration

Ein intelligenter Agent, der täglich personalisierte Briefings erstellt, indem er Wetter-, Surf-, News- und Zitat-Daten parallel sammelt und mit einem LLM zu einem kohärenten Bericht zusammenfasst. Das System nutzt LangGraph für die orchestrierte Datenverarbeitung und verschiedene APIs für aktuelle Informationen.

  • Parallele Datenverarbeitung: Vier Nodes sammeln gleichzeitig Informationen aus verschiedenen Quellen
  • KI-gestützte Synthese: LLM kombiniert alle Daten zu einem natürlichen, gesprächsartigen Briefing
  • Konfigurierbare Parameter: Standort, Surf-Spots und News-Themen individuell anpassbar

Annalanah Sales Assistant

React · Typescript · Go · PostgreSQL · Neon · CI/CD · Render · Lovable

Ein praxisnahes Projekt für eine Freundin, bei dem mehrere Excel-Tabellen in eine Sales Assistant Web App überführt wurden. Die App unterstützt das Sales Personal bei der Verwaltung von Leads sowie bestehenden KundInnen. Darüber hinaus bietet sie ein Workshop-Management-System, mit dem neu gewonnene KundInnen verknüpft werden können. Zur Verbesserung der Benutzererfahrung habe ich OpenAI für Natural Language Processing integriert, sodass Kundendaten einfach per natürlicher Sprache durchsucht werden können. Die Anwendung wurde mit einem auf Lovable basierenden React-Frontend und einem Go-Backend entwickelt. Sie nutzt PostgreSQL, gehostet auf Neon für die Datenspeicherung und verfügt über CI/CD-Pipelines für die automatisierte Bereitstellung auf Render.

  • Frontend: React-App, entwickelt mit Lovable und Typescript, deployed auf Render
  • Backend: Entwickelt in Go, handhabt Datenaggregation & Datenverarbeitung über API und OpenAI-Integration
  • Datenbank: PostgreSQL gehostet auf Neon
  • CI/CD: Github Actions / Render hooks für automatisierte Deployments

CSV TidyImport

Python · YAML · CLI

Eine kompakte, erweiterbare CLI und ein Backend, die unstrukturierte CSVs mithilfe deklarativer YAML-Regeln bereinigen, validieren und normalisieren. Das Projekt kombiniert einen spezifikationsbasierten Validator mit einer Transformations-Engine, sodass Importe wiederholbar, nachvollziehbar und produktionsreif sind. Die Ausgaben sind dank austauschbarer CSV- und JSON-Exporte flexibel und lassen sich leicht integrieren.

  • Bibliothek: Reines Python mit einem CLI-Einstiegspunkt (importierbares Modul + console_scripts).
  • Funktionen: Spezifikationsbasierte Validierung, Transformations-Engine, austauschbare Exporte

Eisbach Tracker 🌊

Vue 3 · Vite · Tailwind · Go · PostgreSQL · Docker · CI/CD · GitHub Pages

Ein Echtzeit Surf Monitor für die Eisbachwelle in München. Ich habe ihn entwickelt, um die Wellenbedingungen mithilfe verschiedener APIs und Web Scraping zu überwachen und die aktuelle Besucherzahl vorherzusagen. Es handelt sich um eine PWA, die zeigt, wie ich Daten aus verschiedenen Quellen abrufe und darstelle, CI/CD implementiere und schließlich das Backend auf einem Server deploye, während das Frontend auf GitHub Pages gehostet bleibt.

  • Frontend: Vue 3 App, gebaut mit Vite und gestylt mit Tailwind, als PWA auf GitHub Pages veröffentlicht
  • Backend: In Go geschrieben, aggregiert und verarbeitet Daten über APIs und Web Scraping
  • Datenbank: PostgreSQL auf Neon gehostet zur Speicherung historischer und aktueller Surfdaten
  • CI/CD: Dockerisiertes Backend mit automatisiertem Deployment auf Render

Rent and Repair Shop

Flutter · Spring · PostgreSQL · Docker · CI/CD · Render

Ein praxisnahes Projekt für einen Freund zur Verwaltung eines Surfbrett-Verleihs und einer Reparaturwerkstatt. Das Projekt basiert auf Flutter. Da das Backend derzeit auf der kostenlosen Render-Stufe läuft, kann das Laden etwas dauern, wenn man die GitHub-Pages-Demo aufruft. Das Backend wurde mit Spring entwickelt und nutzt PostgreSQL als Datenbank.

  • Frontend: Flutter app deployed to Github Pages
  • Backend: Spring Boot application handling business logic, hosted on Render
  • Database: PostgreSQL hosted on Neon
  • CI/CD: Github Actions / Docker / Render hooks for automated deployment
