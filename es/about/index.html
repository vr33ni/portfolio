Sobre Mí

Soy una desarrolladora web full-stack con más de 5 años de experiencia creando aplicaciones web escalables y de alto rendimiento. Me especializo en frameworks modernos de frontend como Vue.js y Stencil, así como en desarrollo backend utilizando Node.js, Go y Java (Spring Boot).

Más allá del desarrollo de aplicaciones, tengo experiencia práctica trabajando con pipelines de CI/CD, contenerización utilizando Docker y despliegue de aplicaciones en plataformas como OpenShift. He ayudado a equipos empresariales a construir plataformas listas para producción, y ahora me enfoco en ofrecer esa misma calidad a startups, agencias y empresas que necesitan código limpio y confiable.

En qué puedo ayudarte:

  • Crear SPAs rápidas y responsivas usando Vue.js
  • Desarrollar componentes web reutilizables con Stencil
  • Desarrollar APIs REST seguras y escalables (Node.js / Express / Java Spring Boot)
  • Integrar APIs de terceros, bases de datos y plataformas en la nube
  • Corregir errores, mejorar el rendimiento y refactorizar código legado
  • Colaborar con diseñadores o equipos para convertir especificaciones en productos reales
  • Pipelines de CI/CD, Docker y Despliegue: Configuración de flujos de trabajo automatizados con GitHub Actions, contenerización de aplicaciones con Docker y despliegue en plataformas como OpenShift.

Valoro la comunicación clara, la arquitectura limpia y los tiempos de entrega rápidos. Si estás buscando una desarrolladora confiable que cumpla con lo prometido — hablemos.
