# Portfolio

A basic overview of my background and work built with Jekyll + Tailwind CSS and deployed to Github Pages.

## Installation

```bash
# Clone the repository
git clone git@gitlab.com:vr33ni-personal/portfolio.git

# Navigate to the project directory
cd portfolio

# Run locally
bundle exec jekyll serve
```
