About Me

I'm a full-stack web developer with 7+ years of experience building scalable web applications. I work across the stack — Vue, React, and Stencil on the frontend, Spring Boot and Go on the backend — with solid experience in CI/CD, Docker, and OpenShift. I've helped enterprise teams build production-ready platforms, and I care about clean architecture, fast feedback loops, and code that's built to last. I'm equally comfortable reviewing a PR, debugging a pipeline, or pairing on a new feature. Outside of work, I'm into surfing, bouldering, and picking up new languages — the spoken kind and the scripted kind.

What I can help you with:

  • Building fast, responsive SPAs using Vue/React + TypeScript
  • Developing reusable web components built with Stencil
  • Developing secure and scalable REST APIs (Spring/Go/Node.js) with clean architecture
  • Integrating third-party APIs, databases, and cloud platforms
  • Fixing bugs, improving performance, and refactoring legacy code
  • Collaborating with designers or teams to turn specs into reality
  • Setting up CI/CD pipelines with GitHub Actions, Docker, and OpenShift

I value clear communication, clean architecture, and fast turnaround — whether I'm joining your team or helping you ship a project. Let's talk.
