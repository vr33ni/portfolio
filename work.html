Eisbachtracker 🌊

Vue.js · Firebase · Geolocation API

A real-time surf tracker for the Eisbach wave in Munich. I built this to monitor wave conditions and crowd levels using various APIs and web scraping. It is a PWA that shows how I retrieve and present data from various data sources, work with CI/CD, and finally deploy my backend to a server,, while sticking to Github Pages for the frontend.
