Morning Briefing Agent

Python · LangGraph · API Integration

Un agente inteligente que recopila automáticamente información meteorológica, condiciones de surf, noticias y citas inspiradoras para generar un briefing matutino personalizado. Utiliza LangGraph para coordinar múltiples fuentes de datos y sintetizar todo en un resumen conversacional coherente.

  • Procesamiento paralelo: Recopila datos de múltiples APIs simultáneamente para mayor eficiencia
  • Síntesis inteligente: Combina información diversa en un briefing personalizado usando LLM
  • Configuración flexible: Personalizable por ubicación, temas de noticias y preferencias del usuario

Annalanah Sales Assistant

React · Typescript · Go · PostgreSQL · Neon · CI/CD · Render · Lovable

Un proyecto de caso real para una amiga, en el que se migraron varias hojas de Excel a una aplicación web de asistente de ventas que ayuda a los empleados de ventas a gestionar tanto los leads como los clientes existentes. Además, incluye un sistema de gestión de workshops al que se pueden vincular los nuevos clientes adquiridos. Para mejorar la experiencia del usuario, integré OpenAI para procesamiento de lenguaje natural, lo que permite buscar fácilmente entre los datos de los clientes mediante lenguaje natural. La aplicación está construida con un frontend en React basado en Lovable y un backend en Go. Utiliza PostgreSQL alojado en Neon para el almacenamiento de datos y cuenta con pipelines de CI/CD para el despliegue automatizado en Render.

  • Frontend: React app desarrollado con Lovable, Typescript, desplegado en Render
  • Backend: Desarrollado en Go, maneja la agregación de datos y el procesamiento a través de la API y la integración con OpenAI
  • Base de datos: PostgreSQL alojado en Neon
  • CI/CD: Github Actions / Render hooks para despliegue automatizado

CSV TidyImport

Python · YAML · CLI

Una CLI y backend compactos y extensibles que limpian, validan y normalizan CSV desordenados usando reglas declarativas en YAML. El proyecto combina un validador basado en especificaciones con un motor de transformación para que las importaciones sean repetibles, auditables y aptas para producción. Las salidas son flexibles mediante exportadores de CSV y JSON enchufables para una integración sencilla.

  • Biblioteca: Python puro con un punto de entrada CLI (módulo importable + console_scripts).
  • Características: Validación basada en especificaciones, motor de transformación, exportadores enchufables

Eisbachtracker

Vue.js · Go · Python · PostgreSQL · Machine Learning · PWA

Una aplicación web progresiva (PWA) full-stack que rastrea la actividad de surfistas y las condiciones del agua en la famosa ola Eisbach de Múnich. Combina monitoreo de datos en tiempo real con análisis predictivo para pronosticar los niveles de multitud.

  • Frontend: PWA construida con Vue.js y Capacitor para experiencia móvil nativa
  • Backend: API REST en Go con PostgreSQL para gestión de datos y despliegue en Render
  • ML: Modelo de regresión lineal en Python/Flask que predice multitudes basándose en condiciones climáticas

Rent and Repair Shop

Flutter · Spring · PostgreSQL · Docker · CI/CD · Render

Un proyecto real desarrollado para un amigo que gestiona una tienda de alquiler y reparación de tablas de surf. El proyecto está hecho en Flutter. Dado que el backend actualmente funciona en el nivel gratuito de Render, puede tardar un poco en cargar cuando se accede a la demostración en GitHub Pages. El backend está construido con Spring y utiliza PostgreSQL como base de datos.

  • Frontend: Flutter app deployed to Github Pages
  • Backend: Spring Boot application handling business logic, hosted on Render
  • Database: PostgreSQL hosted on Neon
  • CI/CD: Github Actions / Docker / Render hooks for automated deployment
